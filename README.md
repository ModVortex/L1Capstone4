# L1Capstone4
This is a program that stores information of different shoes from differnet countries and display info of them.
U also have the abillity to add new shoes.
This program reads from a text file inventory.py to store or use the info.
The user can choose from a variaty of options for example: Searching a shoe with the shoe code, re_stocking on the lowest quantity shoe,
displaying the shoe with the highest quantity etc.
